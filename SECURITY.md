# Security

MachineSight reads local log files and writes `summary.txt`, `findings.csv`, and `intervals.csv` in the output directory you name. It does not open a network connection, start another program, or send commands to equipment.

Please report a vulnerability through private GitHub vulnerability reporting on this repository:

https://github.com/Harry0052/machinesight/security

Do not open a public issue for a report that has not been fixed. Give the version or commit, the input that triggers the problem if you can do that without including credentials or personal data, and the effect you observed.

A disagreement in a report is not a safety instruction.
